### 👋 About me

I'm a **Senior Architect at IBM** with **13+ years** of full-stack engineering experience across product companies, banking and enterprise consulting — including stints at **HPE (via TEKsystems), Simeio Solutions, Incedo, Société Générale and Spirent Communications**.

- 🔐 I design **identity & access platforms** — multi-tenant SSO, OAuth 2.0 / OIDC / SAML, Microsoft Entra ID integrations
- ⚛️ I build **full-stack products** end to end with React, Angular, Node.js and Java / Spring Boot
- ☁️ I run workloads on **Google Cloud Platform** with containers and CI/CD
- 🌍 I contribute to the **[Open Mainframe Project](https://github.com/openmainframeproject)** (software-discovery-tool)
- 🧑‍🏫 I've spent **10 years teaching** — MERN / MEAN, Java, Python and test automation (Cypress, Playwright, Jest)
- 🎯 Currently focused on: architecture leadership, platform engineering and mentoring the next wave of engineers
